# Catalog and personal flow implementation plan

**Goal:** Make personal flow, charts, playlists and four-category music search usable in the existing Android player.
**Architecture:** Extend the authenticated API in a separate part, keep catalog DTOs separate, reuse the existing player and compact rows. Isolate flow buffering from UI; explicitly distinguish local points from server collection actions.
**Tech Stack:** Flutter 3.47.6, Dart 3.13.5, existing http/sqflite/just_audio/audio_service.
**Spec:** `docs/superpowers/specs/2026-10-03-catalog-design.md`
**Execution:** Inline in this task; existing user authorization covers implementation and release.

## Global constraints

Android API 24+, same signing key, no new server or credentials. Russian interface, existing dark/lime theme. Library remains first tab. Votes start at 10, can be negative, never remove favorites. Preserve queue and media notification resources. Emulator-only integration tests; phone receives only signed updates. No APK delivery through Telegram.

## 1. Catalog API and entities

Files: `lib/data/catalog_models.dart`, `lib/data/catalog_api.dart`, `lib/data/models.dart`, `lib/data/zvuk_api.dart`, `test/catalog_api_test.dart`.
Interfaces: `searchCatalog(String, CatalogKind, {String? cursor}) -> Future<CatalogPage>`; `getPlaylists(List<String>) -> Future<List<PlaylistInfo>>`; `album(String)/artist(String) -> Future<CatalogDetail>`; `personalWave({int count=15}) -> Future<List<Track>>`; `editorialPlaylists()/chartPlaylists()/personalPlaylists()` return playlist metadata. `createPlaylist(String,{List<String> trackIds})`, `renamePlaylist`, `deletePlaylist`, `addPlaylistTracks`, `replacePlaylistTracks`, `setCollectionItem` validate mutation results.
- [ ] Add fixtures that assert category-specific cursors, complete album tracks, owner metadata and false mutation handling.
- [ ] Implement queries verified against upstream sources and live API, keep origin/redirect protections unchanged.
- [ ] Extend cached PlaylistInfo/Track fields with optional defaults so old databases still load.

Example acceptance:
```dart
final page = await api.searchCatalog('song', CatalogKind.album, cursor: 'opaque');
expect(page.items.single.kind, CatalogKind.album);
expect(page.next, 'next-opaque');
await expectLater(api.renamePlaylist('p', 'Name'), throwsA(isA<ZvukException>()));
```
