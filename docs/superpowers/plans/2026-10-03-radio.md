# Contextual flows implementation plan

> **For agentic workers:** Execute inline, task by task. No subagents requested.

**Goal:** Start related-song flows from the catalog or add similar songs without interrupting playback.
**Architecture:** Typed source and API page; existing MusicHandler generation and WaveBuffer guards; shared contextual action sheet.
**Tech stack:** Existing Flutter 3.47.6, Dart 3.13.5, just_audio/audio_service/SQLite. No dependencies or schema migration.
**Spec:** docs/superpowers/specs/2026-10-03-radio-design.md

## Global constraints

Version 1.7.0+10; preserve credentials, ratings, library order, queue and compact rows. Live probes read only. Emulator-only tests. Signed phone update only, no uninstall or Telegram. No credentials in public files or APK.

## 1. API and source

Create lib/data/wave_source.dart, lib/data/radio_api.dart and test/radio_api_test.dart; update zvuk_api.dart/catalog_api.dart and core_test.dart.
- [ ] WaveSource(kind,id,title) with personal default, fromTrack/fromCatalog factories, validated JSON; RadioPage(tracks,cursor).
- [ ] `recommendations(WaveSource source,{int cursor=0,int count=15})`: personal/favorites/playlist call personalWave with optional WaveInput; track/artist/album use recommenderRadio enum TRACK/ARTIST/RELEASE.
- [ ] Tests assert variables/routes, repeated cursor accepted, null items skipped, malformed JSON rejected, old source default.

```dart
final seed = WaveSource.fromTrack(const Track(id: '7', title: 'Song'));
expect(WaveSource.fromJson(seed.toJson()).id, '7');
final page = await api.recommendations(seed, cursor: 15);
expect(page.cursor, 15); // Repeating cursors are valid for this endpoint.
```

## 2. Playback

Modify lib/playback/music_handler.dart and queue_controls.dart; add integration_test/radio_playback_test.dart.
- [ ] Source/cursor owned by handler, optional persistence; `startWave({WaveSource source=const WaveSource.personal()})` and batch fetch keep generation guards.
- [ ] Include seed track in exclusion set; resetting/manual replacement/clear/account change cancel late batches.
- [ ] `appendSimilar(Track track)` snapshots API/account and queue version, reads one batch, filters existing IDs, appends atomically, returns count; stale snapshots throw a retry message. Audio state untouched.
- [ ] Local WAV integration proves seed continuity, restoration, empty/repeated batches, cancellation and append-without-restart.

```dart
final playingKey = music.playlist.entryKey(music.playlist.index);
final added = await music.appendSimilar(track);
expect(added, greaterThan(0));
expect(music.playlist.entryKey(music.playlist.index), playingKey);
```
