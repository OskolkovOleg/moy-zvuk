# Мой Звук 1.6 — очередь и режимы воспроизведения

Продолжаем существующий клиент по разрешению пользователя. Этот этап меняет один подсистемный поток — управление прослушиванием. Версия 1.6.0+9, те же пакеты и подпись. Новые API сервиса не требуются.

## Очередь

- Перестановка перетаскиванием за ручку; меню песни: следующей, убрать. Действия над очередью: перемешать оставшиеся, убрать оставшиеся.
- Текущая песня продолжает звучать при перестановке/удалении других строк. Каждое вхождение имеет устойчивый ключ, дубликаты независимы. Устаревшие индексы после автоперехода или поступления рекомендаций отклоняются с просьбой повторить действие.
- Удаление текущей песни выбирает следующую, если она есть; состояние паузы сохраняется. При удалении последней текущей песни выбирается предыдущая на паузе; при пустой очереди плеер останавливается. История библиотеки и серверные плейлисты не меняются.
- Удаление оставшихся отключает поток и повтор, отменяет незавершённую подгрузку, чтобы удалённые песни не появлялись снова. Перестановка/удаление отдельных рекомендаций сохраняют поток.
- Порядок очереди сохраняется при перезапуске. Открытая очередь не сбрасывает прокрутку при добавлении песен. Индекс системной MediaSession обновляется после изменений.

## Повтор

- Выключен → вся очередь → один трек. В бесконечном потоке доступны выключен / один трек; запуск потока сбрасывает повтор.
- Повтор одного трека действует при естественном окончании. Кнопка «Далее» продолжает переходить вперёд. Повтор всей очереди оборачивает «Далее» с последней песни на первую и «Назад» с первой на последнюю, если позиция <=3 секунд.
- Режим сохраняется в состоянии очереди по аккаунту, старый формат означает выключенный повтор. Android MediaSession получает repeatMode, внешняя setRepeatMode поддержана.
- Строка «Далее» вычисляется без выхода за границы: текущая песня при repeat-one, первая при repeat-all, «Поток подберёт следующую» при ожидании новой порции.

## Таймер

- 5, 15, 30, 60 минут; «После песни»; отмена. Отсчёт виден в плеере. По времени ставит паузу и отменяет отложенный автозапуск; «После песни» останавливает при ближайшем естественном окончании до повтора/продолжения потока.
- Ручное переключение не отменяет таймер. Пауза не продлевает дедлайн. Ручная остановка, смена аккаунта и закрытие процесса сбрасывают таймер; он не восстанавливается на следующий запуск. Приложение и так восстанавливает очередь на паузе.
- Фоновый Dart AudioService остаётся владельцем таймера; UI только задаёт состояние и показывает остаток. Проверить на эмуляторе в фоне и при медленной загрузке.

## Реализация и проверка

PlaybackQueue получает ключи вхождений, revision, remove/move/shuffleUpcoming/clearUpcoming. MusicHandler сохраняет выбор по вхождению и состояние воспроизведения, обрабатывает повтор и таймер. Небольшая чистая SleepTimerState хранит дедлайн/режим. QueueView выносится в отдельный файл; компактные режимы и выбор таймера в playback_controls.dart. Нельзя менять системные ресурсы уведомления и существующие оценки.

Тесты: очередь с дубликатами, индексы при перемещении/удалении, stale revision, пределы и восстановление; чистый таймер; реальное естественное завершение коротких WAV с repeat-one/all, ручной skip, таймер/пауза и pending load; неизменность текущего звука при редактировании очереди, пауза при удалении последнего, отмена pending wave при очистке. UI: перетаскивание, меню, таймер, последний элемент потока, узкий экран/1.6× шрифт. Регрессия уведомлений. Подписанный APK, отсутствие секретов/тестов в релизе, обновление поверх 1.5.

Физический телефон ранее не определялся; не спрашивать повторно без новой информации. Если появится — установить напрямую -r. Никогда не удалять личную установку и не запускать на ней тесты. Telegram не использовать.
