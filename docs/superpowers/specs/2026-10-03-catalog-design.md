# Каталог и персональный поток — 1.4.0

## Назначение
Расширить существующий Flutter-плеер музыкальными функциями Звука. Сохранить компактную библиотеку, начальные 10 баллов, ручной порядок, рейтинг, очередь и уведомление.

## Навигация и интерфейс
Четыре вкладки: Библиотека (стартовая), Обзор, Поиск, Плейлисты. Настройки — кнопка сверху. На новых экранах повторяются тёмная тема, лаймовый акцент, отступы 20 dp, компактные треки и мини-плеер. Обзор: одна заметная кнопка «Мой поток», ниже персональные подборки, чарты, редакторские подборки. Данные загружаются при открытии раздела, ошибки имеют повтор, пустые состояния различают отсутствие результатов и сбой сети.

## API
Использовать существующий HTTPS-клиент с запретом передачи токена на иной origin. Запросы проверены по установленному zvuk-music и публичному клиенту zvuk.com, затем на настоящем API. Поиск получает отдельные курсоры для песен, артистов, альбомов и плейлистов. Альбом открывает свои треки, артист — популярные треки и альбомы. Плейлист хранит ownerId; редактировать можно только свой.
Персональные подборки: серверные списки 6, 3, 4, 9, 11, 12, 13. Чарты: проверенные на сайте 1062105, 6477976, 6477975; содержание всегда загружается с сервера. Редакторские подборки — grid/content editorial_playlist.

## Изменения коллекции
Создание, переименование и удаление своего плейлиста; добавление трека через меню песни; удаление отдельного вхождения. Сохранение/удаление песни или чужого плейлиста в коллекции — отдельные явные команды. Кнопки −/+ меняют исключительно локальные баллы. Запросы сериализованы по объекту, ошибка не показывает ложный успех. Нельзя затирать список чужого плейлиста.

## Поток
Настоящий personalWaveContent. Получать порции рекомендаций, пополнять очередь заранее и при достижении конца. Сохранять режим потока в очереди; восстановление на паузе. Запуск обычного списка отменяет ожидающую порцию потока. Пауза во время запроса не должна неожиданно включать музыку. Пропуск и автоматическое окончание продолжают поток, ошибка сети оставляет доступный трек и позволяет повторить. Дубли внутри порции и недавние повторения отбрасываются; нет бесконечного цикла при пустом ответе.

## Проверка и выпуск
Фикстуры API проверяют форму запросов, пагинацию, права и ошибки мутаций. Отдельные проверки потока: продолжение, повторный запрос, отмена устаревшего результата, восстановление, обычный список конечен. Интеграционные UI и фоновые проверки только на отдельном эмуляторе, включая 360 dp и шрифт 1,6×. Живой API — чтение и временный созданный тестом плейлист; существующую личную коллекцию не менять. Release APK проверять на прежнюю подпись, шесть ресурсов уведомления и отсутствие секретов/тестового кода. Выпустить на публичный GitHub, синхронизировать частную копию и установить через USB поверх приложения при доступном телефоне.
