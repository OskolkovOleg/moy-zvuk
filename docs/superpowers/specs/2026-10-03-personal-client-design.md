# Мой Звук 1.5 — личная коллекция и тексты

Следующий законченный этап существующего Flutter-клиента: сохранённые альбомы и исполнители, недавние прослушивания, текст песни. Пользователь разрешил продолжать разработку клиента, публичные релизы и установку поверх приложения по USB; дополнительные согласования для этого этапа не нужны.

## Поведение

- В библиотеке компактный горизонтальный ряд «Альбомы», «Артисты», «История». Переходы открывают отдельные экраны, сохраняя мини-плеер. Основной список песен остаётся компактным.
- Сохранённые альбомы/исполнители загружаются из collection.releases/artists, метаданные пачками по 50. Кэш принадлежит аккаунту. На странице альбома/исполнителя кнопка сохранения работает через существующую очередь серверных изменений. Устаревший запрос не отменяет новое сохранение, ошибка чтения после успешной записи не вызывает повторную запись.
- История показывает последние уникальные песни, новые сверху. Два фильтра: «На устройстве» (до 200 последних песен, автоматически после реального начала воспроизведения) и «В Звуке» (страницы по 50, timestamp из API). Серверная история может запаздывать; клиент не подделывает серверные события. Пауза/продолжение не создают новое прослушивание, очередь и неудачная загрузка не записываются. Локальные записи изолированы по аккаунту и транзакционны.
- Текст открывается из плеера и меню песни. Поддерживается обычный текст и LRC: повторные таймкоды, дробные секунды, offset. Текущая строка подсвечивается, нажатие перематывает только если эта песня сейчас играет. Текст относится к открытой песне; если плеер переключился, подсветка и перемотка отключены. Перевод показывается отдельным переключателем, если есть. Нет текста, ошибка сети и повтор запроса — разные состояния. Тексты не сохраняются в репозиторий или APK.

## Границы и структура

API подтверждён чтением 2026-10-03: коллекция, история с limit/offset и /api/tiny/lyrics. Источник схем: установленный zvuk_music и живые ответы API. Новые модели и API в personal_models.dart / personal_api.dart; изменения коллекции в personal_controller.dart (part AppController); история в отдельном HistoryStore; экраны отдельные. Без новых пакетов и миграции SQLite. Версия 1.5.0+8.

Не включаем в этот этап подкасты, скачивание, настройки потока, управление подпиской. Авторизация, баллы, порядок, очередь, фоновые кнопки и подпись APK сохраняются. Телефон никогда не удалять/очищать, тесты только на эмуляторе. Личный токен только из Keychain/secure storage, не в исходники/логи/артефакты.

## Проверка

Тесты формата API и мутаций, гонок коллекции, разбора LRC, транзакционной истории и изоляции аккаунтов. Эмулятор: экраны на 360dp/увеличенном шрифте, переходы, сохранение, история после воспроизведения; регрессия автоматического следующего и уведомлений. Read-only live-тест новых API. Release: анализ, формат, CI, шесть drawable уведомления, подпись, скан секретов, установка -r. Не публиковать личную историю/тексты в скриншотах.
