Дата: 2026-10-03. Начальные 10 баллов, позиция в рейтинге и компактные строки библиотеки.

- 24 проверки core прошли на отдельном эмуляторе Android 11 / API 30. Начальные баллы прибавляются к сумме настоящих голосов при чтении, без миграции базы или искусственных голосов. Проверены старые резервные копии, повторный импорт, отмена, отрицательные значения и сохранение списка после перезапуска.
- UI-проверка без аккаунта сервиса: строка с обычным шрифтом занимает 60 dp вместе с отступами; кнопки − / + выровнены с обложкой и имеют область нажатия 48 × 48 dp. Проверены увеличенный шрифт 1,6×, длинные названия, прокрутка и меню очереди по долгому нажатию.
- При голосовании из фильтра «Без оценок» показывается весь список, поэтому песня не исчезает. Рейтинг полного выбранного списка обновляется в плеере и не зависит от порядка или размера перемешанной очереди. При отсутствии песни в выбранном списке ранг не выдумывается.
- Снимки интерфейса проверены визуально на экране шириной 360 dp. Заголовок библиотеки прокручивается вместе со списком, чтобы крупный шрифт не вызывал переполнения.

- Анализ Dart и проверка форматирования прошли. Готовый release APK сохраняет все шесть ресурсов уведомления; zipalign и подпись прошли, сертификат совпадает с предыдущими релизами. В APK и публикуемых исходниках не обнаружены личный токен и пароль подписи, в APK нет тестового моста или фикстуры.
- Установка подписанного 1.3.0 поверх 1.2.2 на эмуляторе Android 11: Success; холодный запуск: Status ok; журнал crash пуст.
- На физический телефон 1.3.0 пока не установлена: при проверке доступен только эмулятор. Воспроизведение и шторка в этом обновлении не менялись; их предыдущие проверки описаны ниже.

# Проверка 1.2.1

Дата: 2026-10-02. Исправление проверено на физическом Xiaomi с Android 11 / MIUI 13, на подписанном release APK.

## Причина вылета

Журнал телефона показал повторяющийся `IllegalArgumentException: Invalid notification (no valid small icon)` при создании системного уведомления. `aapt2 dump resources` подтвердил отсутствие `drawable/ic_stat_music` в APK 1.2.0: ресурс, используемый по строковому имени из Dart, удалялся оптимизатором. Отладочные тесты не включают это удаление, поэтому раньше дефект не обнаруживался.

Добавлен `res/raw/keep.xml` для сохранения значка. Скрипт сборки теперь проверяет ресурс в готовом APK через `tool/verify_apk.py`: старый APK 1.2.0 проверку не проходит, исправленный 1.2.1 проходит. Основание: [настройка audio_service](https://pub.dev/documentation/audio_service/latest/index.html#android-setup).

## Пройденные проверки релиза

- Прямое обновление физического телефона 1.1.0 → 1.2.1 через `adb install -r`: Success. Package Manager подтвердил versionCode 4 / versionName 1.2.1. Сохранённый вход и библиотека доступны.
- Естественное завершение полного трека при заблокированном экране перевело очередь на следующую позицию; следующая песня играет, PID сохранился. Перемотка или команда next для этого перехода не использовались.
- Три перехода на следующий трек через системные медиакнопки: музыка продолжилась, PID приложения не изменился.
- Пауза и продолжение при заблокированном экране: состояние Android MediaSession меняется на paused/playing; foreground service и уведомление остаются.
- Уведомление содержит действительный ресурс значка и четыре действия.
- В журнале AndroidRuntime/flutter нового процесса ошибок нет.
- Подпись APK совпадает с прежней, zipalign проходит; в APK нет токена, пароля подписи и тестового моста.
- Статический анализ без диагностик. GitHub Actions для исправления 15c03a3: форматирование, анализ и тесты прошли.

APK SHA-256: `3c613f2f11e12749c2815c9b663c38f6bd8e7f534c665a078645af070e94246a`. Размер: 56 836 654 байта.

Длительная работа MIUI, Bluetooth и телефонные звонки ещё не проверены. Релиз 1.2.0 снят с публикации; использовать 1.2.1.

# Проверка 1.2.0

Дата: 2026-10-02. Flutter 3.47.6 / Dart 3.13.5. Android 16 / API 36 и Android 11 / API 30, ARM64 emulators.

- Статический анализ: без диагностик. GitHub Actions: форматирование, анализ и модульные/виджетные тесты прошли на чистом Ubuntu runner.
- Core: 20 тестов пройдены. Оценки и их перенос, ручной порядок, очередь, API на фикстурах, отбор N лучших до перемешивания, дубли и пограничные случаи.
- UI: 4 теста пройдены. Стрелки, увеличенный текст, плеер при ширине 360 dp, переключение режимов, слайдер, запуск лучших песен и восстановление случайной очереди на паузе. Снимки проверены визуально.
- Фоновый плеер на API 36 и API 30: естественное окончание короткого локального WAV без перемотки запускает следующий. Android показывает foreground media notification с кнопками; пауза через MediaSession оставляет уведомление, возобновление работает, конец очереди останавливает музыку.
- Серия из 25 быстрых переключений в очереди из 2000 песен выполнена без падения на API 36 и API 30.
- Релиз: Android API 24+, ARM64 / ARMv7 / x86_64, versionCode 3. Обновление подписанного релиза 1.1.0 → 1.2.0 на API 30 прошло; холодный запуск Status ok, журнал crash пуст. Подпись APK проверена; токенов и ключей в исходниках и APK нет.

## Пределы прежней проверки

Проверки воспроизведения в 1.2.0 выполнялись в debug-сборке. Для релиза проверялись установка и запуск, поэтому отсутствие значка, используемого при воспроизведении, не было обнаружено. В 1.2.1 добавлены проверка ресурса готового APK и реальные проверки воспроизведения релиза на телефоне.
